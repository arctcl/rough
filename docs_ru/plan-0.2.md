# План v0.2 — надёжность (Windows) и улучшения движка

> Статус: **ГОТОВО (v0.2.0)**. `go build`/`go test ./...`/`go vet` чистые, всё закоммичено.

## Сделано
- **faultlog** (`engine/faultlog`): `GoSafe`, `crash.log`+`rough.log`, `MemStats`, `InitSignals`; флаг `--tui-debug` (пауза при краше); перезапуск экрана при панике в чтении событий.
- **CI** (`.github/workflows/ci.yml`): build + test + vet + `-race` (Linux и Windows).
- **Фиксы аудита F1–F7** (pattern, `$`-кавычки, PPM-паники, pluginCache, renderTile, faultlog-мьютекс, мелочи).
- **`var%pat`** (Bash Parameter Expansion) + тесты + доки.
- **async-модель** (плагин-служба): async-кнопки и живые `<plugin>`, мьютекс-защита плагин-API (`engineMu`), фоновый прогон обычных плагинов убран.
- Плагины `ps` (горутины/память) и `chch` (секретные страницы по коду: `AddCheatRoute`/`AddPage`/`OnReady`).
- Документация RU + EN приведена в актуальное состояние.

## Снято (по решению пользователя)
- **ООП-рефакторинг глобалов в `Engine`** — unix-way; гонки решает async-модель, а не перенос глобалов.
- **Лимиты глубины HTML / шагов пайпа** — спекулятивно, в реальных проектах не нужно.
- **Статус-окно** (многострочные ошибки) — мелочь.
