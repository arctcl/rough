# Справочник rough (Reference)

Голые факты для быстрого поиска — не читай подряд, ищи нужное. Пошаговое
обучение — в [`guide.md`](guide.md), здесь только справочные таблицы.

> [!NOTE]
> У каждого плагина есть встроенная справка: `action="man:имя"` — она всегда
> актуальнее этого файла, потому что берётся из кода плагина.

---

## 1. Теги HTML

| Тег | Что делает | Пример |
|---|---|---|
| текст | рисуется как есть | `Привет` |
| `<h1>` / `<p>` | заголовок / абзац | `<h1>Настройки</h1>` |
| `<br/>` | пустая строка | `<br/>` |
| `<b>` / `<i>` | жирный / курсив | `<b>x</b>` |
| `<center>` | по центру | `<center>x</center>` |
| `<div>` | блок | `<div>x</div>` |
| `<row>` | ряд колонок | `<row><div width="50%">…` |
| `<div width="%">` | колонка | `<div width="30%">x</div>` |
| `<div align="center">` | блок по центру | `<div align="center">…` |
| `<div id="id">` | приёмник вывода | `<div id="out"></div>` |
| `<hr/>` | линия | `<hr/>` |
| `<pre>` | моноширинный блок | `<pre>…</pre>` |
| `<button action>` | кнопка-команда | `<button action="cat:/x">` |
| `<input action label output>` | поле ввода | `<input action="man:" label="Пакет"/>` |
| `<checkbox action>` | переключатель | `<checkbox action="toggle:a.conf:debug">` |
| `<select action options label>` | выпадающий список | `<select action="set:…" options="a:b:c"/>` |
| `<table>` | таблица | `<table><tr><td>x</td></tr></table>` |
| `<img src>` | картинка PPM | `<img src="/opt/x.ppm"/>` |
| `<a href>` | переход на страницу | `<a href="/main">На главную</a>` |
| `<plugin name/pipe interval>` | живой контент | `<plugin name="clock" interval="1s"/>` |
| `output="id"` | куда вывести результат | `<button action="…" output="out">` |
| `| confirm` | подтверждение | `<button action="… | confirm">` |

### Цвет

| Атрибут | Что | Значения |
|---|---|---|
| `color="…"` | цвет текста | `#rrggbb`, номер палитры `3`, имя из темы `header_bg`, `color_2` |
| `bg="…"` | цвет фона | то же |

## 2. `tiles.json`: страницы и тайлы

| Ключ | Что | Пример |
|---|---|---|
| `theme` | тема из `themes/` | `"theme": "orange"` |
| `menu` | вкладки внизу (подпись, роут) | `"menu": [["Главная","/main"]]` |
| `pattern` | схема строки тайла (необязательно) | `["id","x","y","w","h","file"]` |
| `/роут` | страница: список тайлов | `"/main": [["cfg","0%","0%","40%","100%","tiles/cfg.html"]]` |

Тайл — массив `[id, x, y, w, h, file]`:

| Поле | Что |
|---|---|
| `id` | имя тайла (видно на рамке) |
| `x, y` | позиция |
| `w, h` | размер |
| `file` | путь к HTML тайла |

Единицы размеров: `%` — процент экрана, `px` — клетки, `vw`/`vh` — доли окна.

## 3. Квик-параметры (контракт плагина)

Каждый плагин сам задаёт свои параметры и их порядок (контракт). Движок даёт
два способа ввода и их смешение.

| Способ | Пример | Замечание |
|---|---|---|
| позиционно (по порядку через `:`) | `chart:0:100:1:2:CPU` | порядок из контракта плагина |
| пропуск параметра (дефолт) | `chart:0:100::2:CPU` | пустой слот `::` |
| флагами | `chart --min=0 --max=100 --title=CPU` | порядок не важен |
| смесь | `chart::100 --title=CPU` | |
| значение с `:`/`\|` | `sed:':':1` | в кавычках |
| произвольный хвост | `ssh:user:host:67:'docker compose down && up'` | последний параметр «глотает» остаток |

> [!IMPORTANT]
> Контракт у каждого плагина свой. Что за параметры и какие дефолты — всегда
> через `man:имя`.

## 4. Диапазоны и циклы

Диапазон в `[...]` разворачивается в перебор значений, выводы склеиваются.

| Форма | Значения | Пример |
|---|---|---|
| `[N-M]` | все числа | `[1-250]` → 1..250 |
| `[N-M:S]` | с шагом | `[0-1000:100]` → 0,100,…,1000 |
| `[a-c]` | буквы | `[a-c]` → a,b,c |
| `[v1,v2,v3]` | список | `[1,4,9]` |
| несколько | декартово произведение | `192.168.[1-2].[1-2]` → 4 адреса |

Диапазон может держать переменную: `[0-$n:500]` раскрывается в момент
выполнения шага (после подстановки `$n`).

Содержимое, не похожее на диапазон (например `[foo]`), не трогается.

**Цикл `loop:N`** — повторяет остальные шаги пайпа N раз, выводы склеивает:
`loop:3 | ssh:...:sl`. `loop:1` — как без цикла. Количество можно взять из
переменной: `loop:$count`.

## 5. Переменные

| Форма | Что |
|---|---|
| `export:имя` | сохранить текущий вывод пайпа в переменную (резервное слово движка) |
| `$имя` | подставить значение |
| `${имя}` | отделить имя от соседей |
| `${f%.log}` / `${f#/var/}` | убрать суффикс / префикс (как в bash) |
| `\$имя` | литеральный `$` (не подставлять) |
| `'$имя'` | внутри кавычек подстановка отключена |
| `unexport:имя` | удалить переменную (антипод export) |
| `export:имя += [ЧИСЛО]` | аккумулятор: прибавить к текущему значению |

`export`/`unexport` — **резервные слова движка**, не плагины. Переменная
доступна всегда и отовсюду; `$имя` подставляется в момент выполнения шага.

## 6. Стандартные плагины

Список доступных плагинов и их параметры — через `action="man:имя"` (в движке
справка генерируется из кода плагина). Основные:

| Плагин | Что делает | Типичный вызов |
|---|---|---|
| `cat` | читает файл | `cat:/etc/hostname` |
| `wc` | считает строки входа | `cat:x | wc` |
| `grep` | оставляет подходящие строки | `cat:x | grep:^server` |
| `head` / `tail` | первые / последние строки | `cat:x | tail:20` |
| `line` | строка или диапазон строк | `cat:x | line:5-10` |
| `sed` | замена текста | `cat:x | sed:old:new` |
| `sort` / `uniq` / `tr` | сортировка / схлопывание / замена символов | `cat:x | sort` |
| `cut` / `awk` | поля и фильтры | `cat:x | cut::2` |
| `ssh` | команда на удалённом сервере | `ssh:user:host::cmd` |
| `curl` | запрос по URL | `curl:https://…` |
| `man` | справка по плагину | `man:ssh` |
| `chart` | живой столбчатый график | `… | chart:0:100:1:2:CPU` |
| `clock` | часы | `<plugin name="clock"/>` |
| `set` / `toggle` | правка конфигов `ключ=значение` | `set:app.conf:loglevel:info` |
| `theme` | список/смена темы | `theme:list`, `theme:orange` |
| `ps` | процессы/горутины движка | `ps` |

Полный список и справку по каждому — `man:имя`.
