# rough

ROUGH outlines UI -- go html
Это тайловый движок для быстрого поднятия интерфейса в терминале с использованием микса html разметки и linux-like команд

Без веб-сервера, без браузера, как библиотека твоего проекта или stand-alone утилита с ssh и curl и что ты еще придумаешь, по идее хоть в COM порт подключай и управляй станком или пили редактор конфигов, чтобы любой эникей не смог ничего лишнего натыкать в серверах

## Как это выглядит

Ввёл имя пакета в поле — справка появилась в соседнем тайле:

```html
<!-- тайл «ввод» -->
<input action="man:" output="out" label="Пакет"/>

<!-- тайл «вывод» (id="out"): сюда движок рисует справку по команде -->
```

`man` — команда вывода, как `cat`: что выполнил, то и показал. Кнопка, поле ввода, пайп — всё это команды, и результат любой из них можно направить в свой тайл.

## Как подключить

4 строчки:

```go
//go:embed rough
var roughDir embed.FS

func main() { rough.TUI(roughDir) }
```

Всё (движок + плагины + данные) вшивается в один файл. Запуск: `myapp -tui`.

> **Терминал должен быть в UTF-8.** На Windows: `chcp 65001` или используй
> Windows Terminal / VS Code — иначе кириллица и рамки разъезжаются кашей.

## Конфиг — тайлы в JSON

Раскладка экрана — обычный `tiles.json`: страницы, тайлы, их координаты.
Вёрстка каждого тайла — отдельный HTML-файл:

```json
{
  "паттерн": ["id", "x", "y", "w", "h", "файл"],
  "/main": [
    ["hello", "0%", "0%", "40%", "40%", "tiles/hello.html"],
    ["cfg",   "40%", "0%", "60%", "100%", "tiles/cfg.html"]
  ]
}
```

Страница — это роут (`/main`), внутри — список тайлов. Координаты можно
в процентах (`%`), пикселях (`px`) или долях окна. Всё это (JSON + HTML +
плагины) вшивается в бинарник.

## Что можно построить

**Админка.** Чекбоксы настроек, таблицы, SQL в sqlite:

```html
<checkbox action="toggle:app.conf:logging">Логи</checkbox>
<button action="sql:SELECT * FROM errors">Ошибки</button>
```

**SSH-оркестратор.** Кнопка «раскатать апдейт» — сама обходит подсеть, ключи в папке:

```html
<button action="deploy:172.0.0.127:25 | confirm">Раскатать апдейт</button>
```

**Любая автоматика.** Графики по таймеру, аварийные кнопки:

```html
<plugin pipe="file:/tmp/core_temp | bars:temp=(\d+)" interval="1s"/>
```

## Идея

- движок = пустая рамка + курсор; вся логика — плагины
- кнопка = вызов плагина: `<button action="cat:/etc/hostname">`
- всё нативно в Go — ssh, curl, sqlite; работает даже в scratch-контейнере
- справка по плагинам — прямо в интерфейсе (`man`)
