# СМОТРЕТЬ В ПОНЕДЕЛЬНИК

План на понедельник. Список — снизу вверх не смотреть, всё равно всё надо.

## 1. Допилить темы
- Довести темы до ума: проверить все ключи тем (рамки/кнопки/поля/статус),
  чего не хватает — добавить, что криво рисуется — поправить.
- Пройтись по готовым темам (`default`, `day`, `orange`, `terminal`):
  чтобы каждая выглядела аккуратно в любом терминале.

## 2. Запоминальщик тем
- Сейчас тема задаётся в `tiles.json`, смена на лету (`theme:имя`) живёт
  только до перезапуска.
- Сделать так, чтобы выбранная тема запоминалась между сессиями
  (куда-то сохранять, и при старте поднимать её, а не дефолт из `tiles.json`).

## 3. Образовательный проект на rough для rough
- Сделать проект, который обучает работе с rough — и сам написан на rough.
  Как «учебник внутри терминала»: тайлы-страницы объясняют теги, плагины,
  пайпы, темы — с живыми примерами, которые можно понажимать.

## 4. Прочитать весь код без ИИ
- Сесть и прочитать весь код руками, без Copilot.
- Цель: самому разобраться в каждой строке и найти то, что ИИ проглядел.
