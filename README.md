# Rough
Rough-Outlines-UI-Go-Html

Че хочу - мне надоело постоянно лезть в веб интерфейсы и/или файлы конфигов
Решений я не нашел - поэтому запилю тайловый html+go движок для поднятия TUI прямо в консоли
чтобы простые админы могли быстро и понятно настроить все что угодно без бесконечной гуглежки и ИИ

Разработчик добавляет интерфейс и настраивает простые тайлы на go, внутри них пишет html верстку и выдает параметры для настройки
Прямо по ссш заходишь и получаешь 1 открытый ссш порт и полноценный интерфейс
Если получится как в старых терминалах управлять мышкой - то вообще будет круто
