# Кукингбук: темы

## 1. Суть

Тема — это «обложка» интерфейса: она задаёт, какими символами рисуются рамки
тайлов, кнопки, поля и статус-строка и в какие цвета всё красится. Тема —
обычный JSON-файл в папке `themes/` проекта. Какая тема активна, написано
в `tiles.json` ключом `"theme"` (по умолчанию — `default`):

```json
{ "theme": "default", ... }
```

Готовый набор уже лежит в `themes/` — `default`, `day`, `orange`, `terminal`.
Свою тему легко сделать по образцу: скопировать готовую, поменять пару
символов и цветов — и интерфейс неузнаваем.

## 2. Из чего тема состоит

Тема — это два блока: `symbols` (какими знаками рисовать рамки, кнопки, поля,
курсор) и `colors` (какими цветами красить фон, текст, рамки, заголовки). Вот
тема `default` целиком:

```json
{
  "name": "default",
  "symbols": {
    "tile_tl": "╔", "tile_tr": "╗", "tile_bl": "╚", "tile_br": "╝",
    "tile_h": "═", "tile_v": "║",
    "button_l": "⟨", "button_r": "⟩",
    "input_l": "[", "input_r": "]",
    "input_icon": "✎", "cursor": "█",
    "status_tl": "╔", "status_tr": "╗", "status_bl": "╚", "status_br": "╝",
    "status_h": "═", "status_v": "║"
  },
  "colors": {
    "bg": "#1e1e1e",
    "fg": "#d4d4d4",
    "frame": "#569cd6",
    "header_bg": "#1e1e1e",
    "header_fg": "#d4d4d4",
    "title_fg": "#4ec9b0",
    "status_fg": "#dcdcaa",
    "input_fg": "#9cdcfe"
  }
}
```

`name` — имя темы (для `theme:name` и списка). Остальное — символы и цвета;
не задал ключ — возьмётся дефолт из движка (см. ниже).

## 3. Символы

Каждый символ — ключ темы, который движок подставляет при отрисовке. Если ключ
не задан — берётся дефолт из таблицы:

| Ключ | Что рисует | Дефолт |
|---|---|---|
| `tile_tl/tr/bl/br` | углы рамки тайла | `┌ ┐ └ ┘` |
| `tile_h` | горизонтальная линия рамки | `─` |
| `tile_v` | вертикальная линия рамки | `│` |
| `button_l/r` | скобки кнопки | `⟨ ⟩` |
| `input_l/r` | рамка поля ввода | `[ ]` |
| `input_icon` | иконка поля ввода | `✎` |
| `select_icon` | иконка выпадающего списка | `▼` |
| `cursor` | курсор в поле | `█` |
| `status_tl/tr/bl/br` | углы рамки статус-строки | `┌ ┐ └ ┘` (фоллбэк — tile) |
| `status_h` | горизонтальная линия статус-строки | `─` (фоллбэк — tile_h) |
| `status_v` | вертикальная линия статус-строки | `│` (фоллбэк — tile_v) |

Хочешь «двойные границы» — просто замени углы и линии на `╔═╗║╚╝`, как в теме
`default`.

## 4. Цвета

Цвет в теме — это **ссылка** на палитру терминала, hex или имя из темы:

- `"3"` — номер палитры терминала (юзер сам перекрасил его в настройках);
- `"#569cd6"` — жёсткий hex, одинаковый у всех;
- `"red"` — имя палитры tcell;
- ссылка на другой ключ темы (например `"frame": "title_fg"`).

Что красят ключи цветов:

| Ключ | Что красит |
|---|---|
| `bg` | фон экрана по умолчанию |
| `fg` | цвет текста по умолчанию |
| `frame` | рамки тайлов |
| `header_bg/fg` | шапка (строка с роутом) |
| `title_fg` | заголовки тайлов, активная вкладка |
| `status_fg` | статус-строка внизу |
| `status_bg` | фон статус-строки (по умолчанию — `bg` темы) |
| `input_fg` | поле ввода / окно ввода |

## 5. Цвета для плагинов: `color_0` … `color_15`

Это палитра терминала из 16 цветов (тёмные 0–7, яркие 8–15). Плагины берут
свои цвета отсюда через движковый `engine.ThemeColor("color_N", дефолт)` или
оборачивают вывод в маркер `\x01{color_N}…\x01{}` (движок красит, маркеры
невидимы и не ломают ширину). Цвета закреплены за смыслом, чтобы интерфейс
выглядел единообразно:

| Ключ | Смысл |
|---|---|
| `color_0` | чёрный — тень, фон под выделением |
| `color_1` | красный — ошибки, критические сбои |
| `color_2` | зелёный — успех, OK (столбики графиков) |
| `color_3` | жёлтый — предупреждения, конфиги |
| `color_4` | синий — папки, ветки |
| `color_5` | пурпурный — изображения, аудио |
| `color_6` | циановый — симлинки, метаданные |
| `color_7` | светло-серый — текст по умолчанию |
| `color_8` | тёмно-серый — комментарии, второстепенное |
| `color_9` | ярко-красный — критические ошибки |
| `color_10` | ярко-зелёный — активные службы, промпты |
| `color_11` | ярко-жёлтый — строки кода, важные логи |
| `color_12` | ярко-синий — заголовки, ссылки |
| `color_13` | ярко-пурпурный — отладка, спецсимволы |
| `color_14` | ярко-циановый — интерактив, URL, имена |
| `color_15` | белый — основной текст |

## 6. Тема «терминал»: цвета пользователя

Чтобы UI взял цвета из твоего терминала (не жёсткий hex) — ставь **номера
палитры** (0–15): терминал покажет свою перекрашенную палитру.

```json
{
  "name": "terminal",
  "colors": {
    "bg": "0", "fg": "7", "frame": "4",
    "header_bg": "0", "header_fg": "7",
    "title_fg": "12", "status_fg": "11", "status_bg": "0", "input_fg": "14",
    "color_0": "0", "color_1": "1", "color_2": "2", "color_3": "3",
    "color_4": "4", "color_5": "5", "color_6": "6", "color_7": "7",
    "color_8": "8", "color_9": "9", "color_10": "10", "color_11": "11",
    "color_12": "12", "color_13": "13", "color_14": "14", "color_15": "15"
  }
}
```

Даже если терминал перекрашен нестандартной палитрой — движок возьмёт номера
0–15 как есть, и тема подстроится под твои цвета, а не наоборот.

## 7. Смена темы на лету (плагин theme)

```html
<button action="theme:list">Список тем</button>
<button action="theme:orange">Оранжевая</button>
<button action="theme">Текущая тема</button>
```

`theme:ИМЯ` переключает тему сразу (движок перерисовывает на следующем кадре),
`theme:list` — имена файлов `themes/*.json`, `theme` — текущая. В демке testv001
есть страница «Темы» с одним тайлом-выбором.

## 8. Создать тему

Скопируй `themes/default.json` в `themes/my.json`, поменяй `"name"`, символы
и цвета — и укажи тему в `tiles.json`:

```json
{ "theme": "my", ... }
```

Тем можно хранить сколько угодно и переключать на лету плагином `theme` — но
в одной сессии активна одна (задаётся в `tiles.json`). Для переключения можно
сделать и свой плагин, меняющий тему в `engine` — но проще задать нужную
перед запуском.

## 9. Пример: пастельная тёмная с двойными границами

```json
{
  "name": "default",
  "symbols": {
    "tile_tl": "╔", "tile_tr": "╗", "tile_bl": "╚", "tile_br": "╝",
    "tile_h": "═", "tile_v": "║",
    "button_l": "⟨", "button_r": "⟩",
    "input_l": "[", "input_r": "]",
    "input_icon": "✎", "cursor": "█",
    "status_tl": "╔", "status_tr": "╗", "status_bl": "╚", "status_br": "╝",
    "status_h": "═", "status_v": "║"
  },
  "colors": {
    "bg": "#1e1e1e", "fg": "#d4d4d4",
    "frame": "#569cd6", "header_bg": "#1e1e1e", "header_fg": "#d4d4d4",
    "title_fg": "#4ec9b0", "status_fg": "#dcdcaa", "input_fg": "#9cdcfe"
  }
}
```

Тёмный фон, пастельные рамки, двойные линии — аккуратно и в UTF-8 терминале.
