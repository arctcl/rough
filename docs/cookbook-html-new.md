# Кукингбук: HTML — от общего к частному

Пошагово: от «что вообще происходит» до готовой панели. Каждый раздел — маленький
живой пример, который можно вставить и попробовать. Читай подряд, не прыгая.

---

## 1. Что происходит (общее)

У тебя есть **тайлы** — прямоугольники на экране. Внутри тайла — **HTML** (текст,
кнопки, поля). Кнопка несёт **команду** (`action`). Клик → движок выполняет команду →
результат показывается внизу (статус) или в другом тайле.

```
tiles.json ──► какие тайлы и где стоят
tiles/*.html ──► что внутри тайла (текст, кнопки, поля)
кнопка action="cat:/etc/hostname" ──► клик ──► вывод "myhost"
```

**Минимальный пример — тайл с одной кнопкой:**

```html
<h1>Хосты</h1>
<button action="cat:/etc/hostname">Мой hostname</button>
```

Клик → внизу экрана появится имя хоста.

---

## 2. Страницы и тайлы (tiles.json)

**Страница** (роут) — набор тайлов. **Тайл** — прямоугольник с HTML. Что где стоит —
в `tiles.json`:

```json
{
  "theme": "default",
  "menu": [["Главная", "/main"]],
  "паттерн": ["id", "x", "y", "w", "h", "файл"],
  "/main": [
    ["left",  "0%", "0%", "50%", "100%", "tiles/left.html"],
    ["right", "50%", "0%", "50%", "100%", "tiles/right.html"]
  ]
}
```

- `theme` — тема из `themes/` (по умолчанию `default`);
- `menu` — вкладки внизу: пары `[подпись, роут]`;
- `паттерн` — схема строки тайла (можно не писать, дефолт такой же);
- `/main` — страница: список тайлов, каждый — 6 значений по паттерну.

Тайл = `[id, x, y, w, h, файл]`:
- `id` — имя тайла (видно на рамке);
- `x, y, w, h` — позиция и размер: `%` (от экрана), `px` (клетки), `vw/vh`;
- `файл` — путь к HTML.

Тайлы сами растягиваются под размер терминала (ресайз пересчитывает `%`).

---

## 3. Первый тайл: текст и разметка

Всё, что написано в HTML, рисуется как есть. Теги делают текст осмысленным:

```html
<h1>Заголовок</h1>
<p>Обычный абзац.</p>
<br/>                  <!-- пустая строка -->
<b>жирный</b> <i>курсив</i>
<center>по центру</center>
<div>блок текста</div>
<hr/>                  <!-- линия -->
<pre>
   моноширинный блок
   пробелы сохраняются
</pre>
```

Цвет — атрибутом `color` (текст) и `bg` (фон): `#ffcc00`, номер палитры `"3"`,
имя из темы `"frame"`:

```html
<h1 color="#ffcc00">Жёлтый заголовок</h1>
<p bg="4">Синий фон</p>
```

## 4. Кнопка и команда (action)

Кнопка вызывает **команду** — как в Linux. Формат: `имя:арг1:арг2`.

```html
<button action="hello">Поздороваться</button>
<button action="hello:мир">Поздороваться, мир</button>
<button action="cat:/etc/hostname">Показать hostname</button>
<button action="cat:/etc/os-release">Показать os-release</button>
```

- `action="hello"` — вызвать плагин `hello` без аргументов;
- `action="hello:мир"` — вызвать `hello` с аргументом `мир`;
- `action="cat:/etc/hostname"` — вызвать `cat` с файлом.

Параметры можно задать и флагами как в Linux (`cat --файл=/x`) или quick-позиционно —
это определяет сам плагин (смотри его справку через `action="man:имя"`).

Результат без `output` показывается в статус-строке внизу.

---

## 5. Пайп: цепочки команд

Пайп `|` — вывод одной команды на вход следующей (как в шелле):

```html
<button action="cat:/var/log/app.log | tail:20">Хвост лога</button>
<button action="cat:/etc/x.conf | grep:^server | head:5">Серверы (5)</button>
```

`cat` даёт строки → `grep` фильтрует → `head` режет. Ошибка любого шага —
останавливает пайп, сообщение в статус-строку.

---

## 6. Куда идёт результат: статус, блок, переменная

**Без `output`** — результат в статус-строку внизу.

**`output="id"`** — результат в блок `<div id="id">` (в этом тайле, в соседнем,
в другом роуте — где угодно):

```html
<button action="man:ssh" output="out">Справка по ssh</button>
<!-- в любом тайле: -->
<div id="out"></div>
```

**`export:имя`** — сохранить результат в переменную, потом подставить `$имя`:

```html
<button action="ssh:root:srv1::hostname | export:host">Запомнить</button>
<button action="ssh:root:$host::uptime">Uptime на $host</button>
```

---

## 7. Поле ввода: юзер вводит значение

Поле ввода делает команду из своего `action` и введённого текста:

```html
<input action="man:" label="Пакет"/>   <!-- ввёл ssh → man:ssh -->
<input action="set:/etc/app.conf:max_users:" label="Лимит"/>  <!-- ввёл 100 → set:...:100 -->
```

Как работает: клик активирует поле → печатаешь → Enter → движок склеивает
`action` + `:` + ввод → выполняет. Esc — отмена.

**Безопасность:** ввод — всегда одно значение (оборачивается в кавычки). Ввести
`cat | ssh:...` нельзя — это останется текстом, а не командой.

## 8. Управление конфигами: чекбокс и выпадающий список

Файл `app.conf`:
```
debug=1
logging=0
loglevel=info
```

**Чекбокс** — галочка, клик переключает значение в файле:

```html
<checkbox action="toggle:app.conf:debug">Отладка</checkbox>
<checkbox action="toggle:app.conf:logging">Логирование</checkbox>
```

**Выпадающий список** — выбор, который дописывается к команде:

```html
<select action="set:app.conf:loglevel" options="info:debug:trace" label="Уровень"/>
<!-- выбрал debug → set:app.conf:loglevel:debug -->
```

Подменю — `Метка [дети:варианты]`:

```html
<select action="set:app.conf:theme"
        options="Тёмная:Светлая:Цветная [Красная:Зелёная:Синяя]" label="Тема"/>
```

```html
<a href="/main">← На главную</a>  <!-- переход на страницу -->
```

## 10. Живой контент: plugin по таймеру

`<plugin>` сам обновляется по таймеру (без кликов). Интервал — `interval`
(не задан → 2 секунды).

```html
<plugin name="clock" interval="1s"/>                    <!-- часы -->
<plugin pipe="emu_cpu | chart:0:100:1:2:CPU" height="14" interval="2s"/>  <!-- график -->
<plugin pipe="cat:data.log | tail:10 | bars" interval="2s"/>              <!-- спарклайн -->
```

`chart` — живой столбчатый график с осями: `chart:МИН:МАКС[:ШИРИНА[:СЕКУНД[:ЗАГОЛОВОК]]]`.
Высота — из `height`, ширина — из тайла/колонки.

## 11. Собери панель: всё вместе

Одна страница, слева конфиг, справа вывод. `tiles.json`:

```json
{
  "theme": "default",
  "menu": [["Панель", "/main"]],
  "/main": [
    ["cfg", "0%", "0%", "50%", "100%", "tiles/cfg.html"],
    ["out", "50%", "0%", "50%", "100%", "tiles/out.html"]
  ]
}
```

`tiles/cfg.html`:

```html
<h1>Настройки</h1>
<checkbox action="toggle:app.conf:debug">Отладка</checkbox>
<select action="set:app.conf:loglevel" options="info:debug:trace" label="Уровень"/>
<button action="cat:app.conf" output="out">Показать конфиг</button>
<input action="man:" output="out" label="Справка по плагину"/>
```

`tiles/out.html`:

```html
<h1>Вывод</h1>
<div id="out"></div>
```

Всё — кнопки меняют конфиг, чекбоксы переключают, вывод в правый тайл.

## 12. Шпаргалка: теги

| Тег | Что делает | Пример |
|---|---|---|
| текст | рисуется как есть | `Привет` |
| `<h1>` / `<p>` | заголовок / абзац | `<h1>Настройки</h1>` |
| `<br/>` | пустая строка | `<br/>` |
| `<b>` / `<i>` | жирный / курсив | `<b>x</b>` |
| `<center>` | по центру | `<center>x</center>` |
| `<div>` | блок | `<div>x</div>` |
| `<row>` | ряд колонок | `<row><div width="50%">…` |
| `<div width="%">` | колонка | `<div width="30%">x</div>` |
| `<div align="center">` | блок по центру | `<div align="center">…` |
| `<div id="id">` | приёмник вывода | `<div id="out"></div>` |
| `<hr/>` | линия | `<hr/>` |
| `<pre>` | моноширинный блок | `<pre>…</pre>` |
| `<button action>` | кнопка-команда | `<button action="cat:/x">` |
| `<input action label output>` | поле ввода | `<input action="man:" label="Пакет"/>` |
| `<checkbox action>` | переключатель | `<checkbox action="toggle:a.conf:debug">` |
| `<select action options label>` | выпадающий список | `<select action="set:…" options="a:b:c"/>` |
| `<table>` | таблица | `<table><tr><td>x</td></tr></table>` |
| `<img src>` | картинка PPM | `<img src="/opt/x.ppm"/>` |
| `<a href>` | переход на страницу | `<a href="/main">На главную</a>` |
| `<plugin name/pipe interval>` | живой контент | `<plugin name="clock" interval="1s"/>` |
| `output="id"` | куда вывести результат | `<button action="…" output="out">` |
| `| confirm` | подтверждение | `<button action="… | confirm">` |

## 13. Частые вопросы

**Куда делся результат?** Без `output` — в статус-строку внизу. С `output="id"` —
в блок `<div id="id">`.

**Почему у поля ввода `:` в конце action?** Потому что ввод приклеивается к action
последним аргументом: `man:` + `ssh` = `man:ssh`. Без `:` движок добавит сам.

**Можно ли через поле ввода выполнить свою команду?** Нет. Ввод — одно значение
(в кавычках), `|` и `:` в нём не работают как синтаксис.

**Как узнать, какие аргументы у плагина?** Кнопка `man:имя` покажет справку:
`<button action="man:ssh">Справка по ssh</button>`.

**Не работает кириллица?** Терминал должен быть UTF-8: Windows — `chcp 65001`
или Windows Terminal / VS Code.
